# Approved sandbox fixtures

Place only KRA-approved, non-production test payloads in this directory. Never
commit taxpayer personal data, live merchant data, credentials, tokens, or
production payloads. The GitHub sandbox workflow accepts payload paths only
under this directory.

The repository intentionally ships no operation payload examples because the
provided Postman collection does not define authoritative request schemas for
all operations. Obtain and approve each payload with KRA before adding it.
