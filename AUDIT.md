# Repository audit

Baseline main: c8d809e87466c682106e8f9ac1c7d4548b71492e. Python FastAPI/httpx service provides PIN routes, GavaConnect catalog dispatch and a separate direct OSCU sandbox adapter. The current feature branch adds Redis-backed distributed rate limiting/idempotency, encrypted cached responses, a readiness endpoint, seven direct OSCU SDK clients and a canonical 23-operation manifest/OpenAPI contract. Existing JS/PHP examples are clients, not full server implementations.

Known limitations: KRA success response fields and error code 30002 are explicitly assumptions in the Python client and require sandbox confirmation. GavaConnect OAuth token caches remain process-local; the Python API's rate limiting/idempotency use shared Redis when configured. Independent language server templates still require shared gateway/state for multi-replica production. A PIN match is not identity proof or tax compliance. KRA production access requires separate approval/credentials. Scope remains PIN Checker and PIN Checker By ID; no scraping.
