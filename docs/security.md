# Security

Keep consumer keys/secrets server-side in a secret manager; never commit them or embed them in browsers/mobile apps. Require TLS, strong high-entropy proxy keys, rotation, consent, request-size limits and upstream timeouts. Never log full PINs, national IDs, access tokens, secrets or raw upstream payloads. Separate sandbox/production credentials. Mock mode must not run in production. The Python FastAPI service uses Redis-backed distributed rate limiting and encrypted idempotency records when `IDEMPOTENCY_REDIS_URL` and `IDEMPOTENCY_ENCRYPTION_KEY` are configured; production startup requires TLS Redis and the Fernet key. Its memory fallback is for local development/tests only. The separate language GavaConnect server templates still use process-local state and require shared gateway enforcement before multi-replica deployment. A PIN match is not identity proof or a Tax Compliance Certificate. Complete legal/privacy review and applicable Data Protection Act obligations before real personal-data processing. Production access requires KRA approval; mock tests do not prove KRA connectivity.
